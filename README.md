# BSense P300 个体短时采集

从 `bsense-lsl` 的 M7 P300 提取出的独立项目，面向固定参赛者的机器狗指令采集与个体校准。默认一次只采一组，可调组数、每个指令的重复次数和每次选择的闪烁轮数。保留原始 EEG、XDF 事件、匿名身份、Session、真实目标和软件时序记录。

## 时长与默认配置

| 配置 | 正式组数 | 每指令次数 | 每次选择闪烁轮数 | 正式采集 | 含检查、练习和休息 |
|---|---:|---:|---:|---:|---:|
| 标准单组（默认） | 1 | 10 | 6 | 9 分 06 秒 | **11 分 31 秒** |
| 现场短测 | 1 | 6 | 4 | 4 分 12 秒 | **6 分 24 秒** |

完整流程：设备检查 30 秒 → 睁眼基线 30 秒 → 说明 10 秒 → 6 次练习 → 休息 20 秒 → 正式采集 → 自动保存。多组时组间休息 45 秒。每次目标提示 1.5 秒，六指令每轮各闪一次，100 ms 高亮、175 ms SOA，末次闪烁后保留 1.3 秒尾段。

界面显示预计总时长。超过 18 分钟的计划不能启动，为系统延迟和准备留余量。从点击开始计时，20 分钟自动结束刺激并保存为 `time_limit`，不会冒充完整完成。文件收尾可能另需数秒。佩戴、电极接触调整和离线训练不计入软件采集时间；若要求从佩戴开始总共 20 分钟，按标准配置预留约 8 分钟，准备超时应改用短测或另约。

同一组中的训练、验证、测试是连续的完整 Trial 分段，界面不中断、不要求受试者重新开始：

- 标准单组：训练 36 次、验证 12 次、独立测试 12 次；每段六指令均衡。
- 现场短测：训练 12 次、验证 12 次、独立测试 12 次。
- 每个指令至少重复 6 次；多组也保留同样的分段规则。
- 练习、基线、设备检查不会进入模型训练。

## 启动

Windows 安装脚本和软件测试已通过 [GitHub Actions](https://github.com/shaun5297/bsense-p300-pilot/actions/runs/34571175832)。实验室首次连设备请按 [Windows 设备试测说明](windows/README.md) 操作；真实设备验证仍待完成。

需要 Python 3.11–3.13（含 Tk），设备软件发布双通道 FP1/FP2 EEG 的 LSL 流。

macOS：

```bash
bash "macos/setup.sh"
bash "macos/run.sh"
```

Windows：先双击 `windows/setup.bat`，安装结束后双击 `windows/run.bat`。两个脚本均保持窗口，错误不会一闪而过。Windows 脚本默认使用 Python Launcher 的 3.12，可在命令行以 `windows\setup.bat 3.13` 指定 3.13。运行环境不能从 Mac 复制到 Windows。

或手动安装：

```bash
python -m venv .venv
# 激活该环境后执行
python -m pip install -e ".[test]"
bsense-p300-pilot
```

只查看默认计划，不连接设备：

```bash
bsense-p300-pilot --plan
```

## 如何重复采集

1. 相同的人一直使用同一个匿名编号，例如 `P001`；不同的人使用不同编号。
2. 每次更换 Session，例如 `20260911_01`、`20260911_02`；同名目录已存在就拒绝覆盖。
3. 点击“标准单组”或“现场短测”，也可自行调整参数，检查预计时长。
4. 扫描后明确选择本次 EEG 流。通道标签缺失时，核实设备通道顺序后手动指定。已标成其他电极位置的流不能强行当作 FP1/FP2。
5. 填写参考电极、原始单位和佩戴变化等备注。开始前完成项目所需的受试说明和同意。
6. 每次根据提示注视指定目标；闪烁期间目标提示和特殊边框隐藏。默数目标亮起次数，不追随其他格子，不用刻意眨眼或面肌动作代替注意。
7. 按 Esc 或“结束并保存”可随时中止。中止、断流、平直信号等记录仍保留，不能直接训练成完整 Session。

本项目只录制明确选择的一路 EEG 和自身 Marker，不要求 fNIRS、心率或厂商全部数据流同时存在。不包含机器狗运动或自动导航代码。

## 个体训练与现场追加校准

采完在界面点击“训练当前受试者模型”。可在“同人历史 Session”填入之前的 Session，逗号分隔。历史数据只合并训练段，当前 Session 的验证和测试段保持独立。

命令行等价操作：

```bash
bsense-p300-train \
  --data-root "$HOME/BSenseDatasets/p300" \
  --subject P001 --session 20260911_02 \
  --history-session 20260911_01 \
  --output-dir "$HOME/BSenseDatasets/p300/models/P001_20260911_02"
```

使用从该受试者数据拟合的标准化 + shrinkage LDA，保持现有机器狗项目的 ERP 预处理、特征和 `artifact_schema_version=2` 格式。不混入其他受试者，不加载旧项目中的实验权重。该方案是同人重新拟合/校准，不是神经网络权重微调。

训练先只使用训练段，再在验证段比较 2 至采集上限轮的六指令结果。项目内部筛选要求：接纳且正确的指令占所有 Trial 至少 80%，接纳指令中的正确率至少 90%；取满足条件的最少闪烁轮数。没有满足条件的配置时，明确返回“暂无可靠建议”，不会靠降低置信度门槛制造通过结果。

选定后冻结模型与参数，再评估独立测试段；不会把测试段重新加入发布模型。输出：

- `model.joblib`：受试者专用候选模型，可被现有 `ModelRuntime` 加载；只能加载自己信任的模型文件。
- `training_report.json`：来源哈希、数据质量、训练划分、验证速度曲线、独立测试结果、拒绝率、错误指令数、带拒绝列的混淆矩阵、正确率区间。
- `speed_profile.json`：该受试者的候选闪烁轮数和验证状态。

12 次测试仍很少。例如 10/12 正确不代表稳定达到 83%；报告同时给出 Wilson 区间。速度曲线使用完整长序列的前缀离线计算，包含提示和尾段耗时估计，不等于短序列在线成绩，更不等于机器狗完赛成绩。软件时序门槛和上述模型门槛都是本项目内部标准。

## 接入机器狗控制台

模型与旧项目兼容；真正缩短闪烁次数还需控制端支持。配套的本地 `bsense-realtime-classifier` 现已增加 `--sequences-per-trial`（2–10，默认仍为 10）。该参数尚未推送 GitHub。取得验证报告后先用 stdout 桥进行桌面联调：

```bash
bsense-dog-controller \
  --model "/absolute/path/model.joblib" \
  --sequences-per-trial 4 \
  --bridge-config "/absolute/path/bsense-realtime-classifier/config/unitree_bridge.json"
```

`4` 只是参数示例，应使用自己的验证建议，并另做在线自由选择验证。现有控制端默认置信度 0.55、领先差 0.08、质量比例 0.8；短序列要求每个指令都获得相应数量的有效闪烁。10 轮默认行为保持原有至少 6 次有效闪烁的要求。

将新项目复制到另一台电脑时，未更新的旧控制台需要同步此接口变更。对应源码补丁保存在 `docs/controller-sequences.patch`；先在目标控制台仓库运行 `git apply --check /absolute/path/controller-sequences.patch` 核对适用性，再按自己的代码变更流程应用。补丁不启动机器人。

本项目不会自动打开控制台、解锁机器人或启动运动。`control_output_enabled=False` 只是模型元数据，旧控制端不强制执行它，不能当作安全机制；真实保护仍来自 stdout 模式、显式解锁、急停和桥接层。

不同环境加载 sklearn 模型应使用匹配的软件版本；本机验证版本记录在 `requirements-tested.txt`。查看 [赛规与现场验证](docs/COMPETITION.md)。

## 文件结构与质量边界

默认数据目录：`~/BSenseDatasets/p300/sub-P001/ses-.../`。

```text
context.json                身份、配置、EEG 元数据、结束状态、时钟统计
events.jsonl                可审计的本机 LSL 时间戳与真实目标事件
*_task-m7_p300.xdf          原始 EEG + 唯一实验 Marker 流
```

XDF EEG 保留源时间戳，通过 ClockOffset 转到本机时钟；Marker 用实际 UI 提交后的本机 LSL 时间戳直接写入同一 XDF。软件时间戳不能证明屏幕实际发光时间，正式提速前应测显示时序。程序检查倒序、缺失片段、样本非有限数、平直通道、闪烁完整性和软件时序；FP1/FP2 的眼动伪迹仍需人工/离线复核。

采集软件记录成功、软件测试通过、离线模型通过与真实脑控完赛是不同结论。当前没有新增真实受试者数据，也没有已验证的准确率提升或真机成绩。
